# ADR-087：大屏自由画布二期（缩放编辑 + 多选与对齐 + 复制粘贴 + 模板）

- 日期：2026-10-11
- 状态：**已交付**（2026-10-11 立项并交付二期 D1~D5；一期见 ADR-086；落地记录见文末）
- 背景：

一期（ADR-086）交付了自由画布模式：像素坐标 + 基准设计画幅、允许重叠、4px 参考线吸附、`ReResize` 承接手势、投屏按设计画幅等比缩放。但设计器目前仍是**单窗格视角**，编辑效率上有四处明确缺口：

1. **看不到全局**：设计画布按 1:1 渲染（1920×1080），普通笔电视口只能靠滚动查看局部，做「整体留白」这类判断必须来回滚动；
2. **只能单个操作**：做「一排等距的卡片」「左对齐的标题栏」只能逐格拖到参考线命中，没有多选、对齐、分布；
3. **复制只有就地一次**：`Ctrl+D` 复制单窗格（走层叠位），没有「剪贴板 → 跨屏 / 跨会话粘贴」；
4. **每次都从空画布开始**：没有可复用的骨架（模板）。

现状约束：

- 交互换算（拖动 / 缩放 / 拖放 / 吸附 / 框选）全部以设计画布 px 为基准，**zoom 只能影响显示与指针换算**，不得进入数据、校验与落库；
- 撤销栈口径是「一步一组」（一期手势 = 一个撤销点）；二期所有批量操作必须同样收敛为单点；
- 保存契约不变：服务端仍是唯一写权威（坐标 + 引用可见性校验），前端不得产生「注定被拒」的写入；
- `ReResize` 保持通用：zoom 以 `scale` prop 注入（默认 1，旧用法零变化），吸附 / 对齐算法继续留在业务侧纯函数；
- 栅格模式（ADR-062）与轮播形态零影响。

## 决策

### D1 Zoom-to-fit（缩放编辑）

- 自由画布设计区新增**显示缩放**（viewport zoom，与数据无关）：范围 25%~200%，档位 25 / 50 / 75 / 100 / 125 / 150 / 200；进入设计器默认「适应窗口」（按滚动容器实测尺寸算，取值到 1%）；工具条提供档位下拉 + 「适应窗口」+「100%」；
- 实现：滚动容器 `.free-board`（viewport）内放 `.free-board__stage`（占位尺寸 = `design × z`），画布元素 `transform: scale(z)` + `transform-origin: 0 0`。**占位尺寸随 z 变化**是滚动条正确的前提（只 transform 不占位会「缩放后滚不到右下角」）；
- **指针换算**：`ReResize` 新增 `scale` prop（默认 1），手势增量除以 scale；组件库拖放 / 框选 / 参考线绘制全部按 z 换算；**属性面板、键盘微调、吸附算法仍是 px 语义**（不受 zoom 影响）；
- `Ctrl/⌘ + 滚轮` 以**指针为锚点**缩放：缩放前后保持指针下的数据点不动（滚动量补偿换算式为纯函数 + 单测）；
- 栅格模式不启用（12 列栅格本就是响应式填充容器，无固定画幅）；zoom 不落库、不参与保存载荷。

### D2 多选

- **选择模型收敛为 `selection: string[]`（有序，末位为主选）**，单选的 `selectedPk` 由它派生（一期调用面语义不变：属性面板 / 快捷键 / 历史裁剪按派生值工作）；历史栈的「恢复后清理已消失的选中」改为按集合裁剪；
- 加选 / 减选：`Shift` / `⌘` + 点击窗格（点已选中项 = 移出选区）；**空白处按下拖拽 = 框选**（矩形与窗格求交即命中，`Shift` 为追加框选）；`⌘/Ctrl+A` 全选、`Esc` 清空；
- **组拖动**：拖动选区内任一窗格 = 整组刚性位移——delta 由被拖窗格给出，**按组统一夹回画幅**（任何一个成员不能越界），吸附参考线按被拖窗格命中后整组跟随；手势中写入各成员数据、**整组只记一个撤销点**（与一期手势口径一致）；
- 视觉：选中窗格描边（一期已有）+ **组包围盒虚线** + 框选矩形（两层都在画布坐标系内，随 zoom 一起缩放）；
- 多选时属性面板切换为**多选面板**：选中数量 + 对齐 / 分布 / 层级 / 复制 / 删除入口（单窗格属性编辑在多选下不适用，避免「改了很多个」的隐式语义）；
- 组删除 / 组复制 = 一步一个撤销点；`Delete`、`Ctrl+D` 对选区生效。

### D3 对齐与分布

- **对齐 6 种**：左 / 水平居中 / 右 / 上 / 垂直居中 / 下；基准 = **选区包围盒**；单选时基准 = **画幅**（等价「对齐到画布」）；
- **分布 2 种**：水平等间距 / 垂直等间距（≥3 个才可用；两端极值不动，中间按「边距均分」排布；允许负边距，保持确定性）；
- 结果一律夹回画幅；一次操作 = 一个撤销点；算法为纯函数（`utils/freeAlign.ts`）+ 单测；
- **层级操作扩展到多选**：置顶 / 置底 / 上移 / 下移按选区在数组中的相对顺序整体处理（选区内部的相对层级不变）。

### D4 复制粘贴

- `⌘/Ctrl+C`：复制选区到内存剪贴板 + `localStorage`（带 `version` 字段与命名空间前缀），支持**跨大屏、跨会话**粘贴；
- `⌘/Ctrl+V`：粘贴为**新 pk**、整体层叠偏移 `+24/+24`、夹回画幅、粘贴后选中新窗格；一次粘贴 = 一个撤销点；超出数量上限时按上限截断并提示；
- `⌘/Ctrl+D`：就地复制（`+24/+24`）；多选 = 整组复制（保持组内相对位置）——与一期单窗格语义兼容；
- **引用可见性过滤（与模板共用同一链路）**：粘贴 / 应用模板时，引用了当前不可见（或已删除）仪表盘 / 数据集的窗格被丢弃，并提示「已跳过 N 个引用不可见的窗格」——把「粘进去但保存 400」提前到粘贴时就暴露；
- 剪贴板载荷带来源画幅（`design_w/design_h`）：跨画幅粘贴**不做比例缩放**（保持 px 语义夹回画幅），避免隐式变形。

### D5 模板

- 形态：**内置模板 3 个** + **「我的模板」（localStorage）**：
  - 内置（前端常量，纯结构、不含任何数据引用，任何环境可用）：**宣传屏**（大标题 + 副标题 + 时钟）、**汇报屏**（标题栏 + 三条正文 + 页脚）、**数据骨架**（标题 + 三分区标题位，供用户绑定仪表盘）；
  - 我的模板：把当前自由画布**保存为命名模板**（画幅 + 窗格结构与样式 + 数据引用），支持应用 / 重命名 / 删除 / 导出 JSON；
- **应用模板**与**粘贴**共用同一条插入链路（过滤不可见引用 → 新 pk → 偏移 → 夹回 → 数量上限），因此模板与剪贴板行为一致、只有一份实现；
- 应用模式二选一：**替换**（清空当前自由窗格后应用，二次确认）/ **追加**（层叠到当前画布）；一次应用 = 一个撤销点；
- 内置模板不可改名 / 删除；我的模板导出 JSON 便于备份与人工编辑（**导入**登记为后续，触发条件：团队共享模板诉求出现时与服务端模板一起做）——**两项均由 [ADR-088](ADR-088-screen-canvas-toolkit-3.md) 提前交付**。

### D6 边界（本 ADR 当时不做；**五条已全部由 [ADR-088](ADR-088-screen-canvas-toolkit-3.md) 收回**）

- ➡️ 旋转 / 动画 / 富文本 —— [ADR-088](ADR-088-screen-canvas-toolkit-3.md) 已交付；
- ➡️ 元素级「吸附到网格」（保留参考线吸附）—— ADR-088 已交付（参考线优先、网格兜底）；
- ➡️ 多选批量改属性 —— [ADR-088](ADR-088-screen-canvas-toolkit-3.md) 已交付（**统一值语义**：控件显示选区公共值，多值不一时留空，设定即写给全部适用窗格）；
- ➡️ 模板服务端落库与团队共享、模板导入 JSON —— ADR-088 已交付；
- ➡️ zoom 的键盘档位循环 —— ADR-088 已交付（`⌘/Ctrl + = / - / 0`）。

## 备选方案与取舍

| 方案 | 结论 |
|------|------|
| zoom 用 CSS `zoom` 属性（省换算） | **拒绝**：各浏览器语义不一致（指针坐标与 `getBoundingClientRect` 表现不同），且与 transform 混用会双重缩放 |
| zoom 通过「重排数据坐标」（把画幅按 z 缩小后落库） | **拒绝**：污染数据、保存需反算、投屏与设计口径分离，违背「zoom 只作用于显示」 |
| 多选另存一个 `Set` 而不动选择模型 | **拒绝**：两个真相源必然漂移；本期改为 `selection` 单一真相 + 单选取值派生 |
| 组拖动用水印/临时 transform 预览（手势中不写数据） | **拒绝**（本期）：成员预览与落库夹取要维护两套几何；改为「手势中按组夹取写入数据、整组一个撤销点」，与一期 props↔box 同步机制一致 |
| 剪贴板走服务端（跨设备） | **拒绝**（本期）：引入模型 + 权限点，跨设备诉求未出现；`localStorage` 已覆盖跨屏 / 跨会话 |
| 模板保存剥离数据引用（纯结构） | **拒绝**：同环境复用会丢引用、每次重绑；改为「保留引用 + 应用时按可见性过滤」，与粘贴同链路 |
| 多选批量改属性 | **已交付（ADR-088）**：取「改成一致」（统一值）语义——控件显示公共值、多值不一时留空，设定即统一写入；「同时改全部（各改各的）」被否（无从表达差异，且撤销语义会碎成 N 步） |

## 兼容性与回退

- 选择模型升级是**内部重构**：`selectedPk` 由 `selection` 派生，一期调用面（属性面板 / 快捷键 / 历史）语义不变；栅格模式保持单选（不引入多选，避免栅格语义复杂化）；
- `ReResize` 新增 `scale` prop（默认 1）与 `snap` 钩子（一期已交付）；旧调用零变化；
- 剪贴板 / 模板是新增入口，隐藏入口即可回退；zoom 默认「适应窗口」且可一键 100%，不影响既有操作习惯；
- 键盘新增 `⌘/Ctrl+C/V/A`：均在「输入控件聚焦时不劫持」口径内，`A` 只在自由模式下生效。

**踩坑与口径（都已进代码注释）**

- **滚轮锚点换算必须先有真实指针坐标**：E2E 里用 `dispatchEvent("wheel")` 不带 `clientX/clientY` 时，指针被当成在容器外，缩回原档位会把容器滚出 47/22px，画布左上角离开可视区（后续框选全部落空）。用例已改为传入视口内坐标，并额外断言「放大再缩回 → 滚动量回到 0」；真实用户路径（`Ctrl+滚轮`）不受影响，锚点公式本身按「指针下的数据点不动」定义；
- 组拖动只在被拖窗格上做吸附，其余成员按同一 delta 刚性跟随，夹取按**组包围盒**统一计算（任一成员越界即整组停住），否则会出现「一个成员贴边、其余继续动」的撕扯；
- 组拖动在手势中即写数据（复用一期「props ↔ box 同值回显忽略」机制），因此**整组共用一个撤销点**（首次移动记点，停手不补记）；
- 框选与组包围盒画在**画布坐标系**内（随 zoom 一起缩放），指针换算一律「先减画布 `getBoundingClientRect()` 起点、再除以 z」；
- 粘贴 / 应用模板的「过滤不可见引用」与保存校验同口径（引用不可见 = 服务端会拒），过滤后不再兜底；内置模板只含文本 / 时钟（零引用依赖），任何环境可直接应用；
- 对齐 / 分布只在**真的产生位移**时记撤销点（连续点同一个对齐按钮不堆空历史）；单选对齐基准 = 画幅，多选 = 选区包围盒；
- **zoom 会缩放窗格手柄的命中区**（`transform: scale()` 一并缩放，8px 手柄在「适应窗口」下只剩约 3px）：一期 E2E 用「手柄角点 +4px」点击右下角手柄，在默认适应窗口下落到窗格本体上（变成拖动，尺寸不变）而失败。用例改为点手柄中心；产品侧口径是「放大后再精修」，手柄尺寸不随 zoom 反缩放（登记为后续可选优化）。
