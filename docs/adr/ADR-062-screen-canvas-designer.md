# ADR-062：大屏画布设计器（P2.2 批次一）

- 日期：2026-09-27
- 状态：**已交付**（backend pytest EXIT=0 + 23 例窗格单测 + 11 例窗格 API 集成测试 / client typecheck + vitest 620 + eslint/prettier/stylelint/i18n + build 与体积门禁 / E2E 双浏览器「设计器主链路 + 数据分析主链路 + 远程控制」6 例通过 / 本地 compose 已迁移与部署）
- 背景：大屏长期只有「仪表盘轮播」一种形态——`Screen.dashboards` 是播放列表，页面把当前仪表盘的卡片按 12 列流式排布，无法把不同仪表盘的卡片放到同一屏的指定位置，也无法加标题/时钟这类非数据组件。对标 JimuReport 类大屏设计器，批次一要交付的是**画布布局**能力本身（栅格 + 组件 + 属性 + 保存/预览），批次二再补报表设计器。

## 决策

### D1 两种形态共存：`layout` 非空即画布，空则维持轮播

- `Screen.layout`（JSONField，默认 `[]`）= 窗格数组；**空即回退轮播**——存量数据、既有页面、既有 E2E 与视觉基线零影响（`dashboards/interval/refresh` 字段全部保留，可在两种形态间来回切换）；
- 前端判定点唯一：`display.vue` 的 `isCanvas`（`layout` 过滤掉对浏览者不可见的仪表盘后非空）。画布态不渲染轮播页码与暂停控件（无「当前看板」概念），远程控制帧的 `refresh` 仍生效、`switch/page` 自然失效。

### D2 窗格模型：12 列栅格绝对定位 + 三类组件

- 坐标系：`x` 列下标（0 起，`x + w ≤ 12`）、`y` 行下标（0 起，`y + h ≤ 60`）；行高与间距由前端常量固定（40px 行高 / 12px 间距，即步长 52px），设计器与投屏页共用同一组常量，保证所见即所得；
- 组件：`dashboard`（内嵌该仪表盘的可见卡片，嵌套 12 列栅格）/ `text`（内容 + 字号 14~72 + 对齐）/ `clock`（时钟文案由父组件统一按秒下发，多窗格共用一个 interval）；
- 窗格标识 `pk` 由前端生成（仅用于定位与列表 key，不承载业务语义）。

### D3 校验落在服务端单一事实源，前端只做「就地吸附」

- `dataset/utils/screen_layout.py::normalize_screen_layout` 是窗格载荷的唯一事实源：归一化（丢弃未声明键、按类型补默认值）+ 校验（类型白名单 / 越界 / 尺寸非正 / **重叠** / 未知仪表盘 / 数量上限 24 / 文本与标题长度），序列化器 `validate_layout` 直接调用；
- **重叠一律拒绝**：栅格画布上重叠几乎总是误操作，且会让「谁在上层」变成隐式行为（要叠放请用更小的窗格或拆屏）；
- 前端镜像同一套几何口径（`utils/layout.ts`，纯函数 + 单测）：拖拽/缩放先算格数增量，落点非法**保持原位**（不弹错、不发注定被拒的请求），新增窗格用 `findSlot` 行优先找首个空位，画布排满给可读提示；
- `bool` 不是合法数值：Python 里 `True` 会被静默当成 1，序列化校验显式拒绝（单测锁定）。

### D4 交互与页面组织

- 设计器为独立全屏页（隐藏静态路由 `/analysis/screen/designer?pk=`，与大屏投屏页同族），入口在大屏列表行操作「设计」（`partialUpdate:DataScreen` 权限）；
- 三栏：左组件库（文本 / 时钟 / 仪表盘清单）+ 中画布（栅格底板、拖拽移动、右下角缩放、删除）+ 右属性面板（标题覆盖 / 仪表盘切换 / 文本内容与字号对齐 / 精确位置尺寸）；
- 投屏与设计器共用 `ScreenPane.vue` 渲染窗格（同一组件、同一深色视觉），避免「设计一套、投屏另一套」的漂移；
- 保存走 `partialUpdate`（`layout` 单字段），本地先 `normalizePanes` 收敛再提交；「清空画布」二次确认后即回到轮播形态。

### D5 刷新与导出在画布态的等价物

- 数据刷新：轮播态逐卡 `loadData`，画布态由 `ScreenPane` 暴露 `refresh()` 逐窗格刷新（`utils/useScreenDisplay.ts` 的定时器只认「一个刷新回调」，两种形态各自实现）；
- 导出 ZIP：轮播态逐卡 `renderImage`，画布态逐窗格 `renderImages()`；「跳过数」= 总卡数 − 实际渲染出的图片数（口径统一到 `collectImages`）。

## 验证

- 后端：窗格纯函数 23 例（归一化 / 越界 / 重叠 / 未知类型与仪表盘 / 上限 / bool 拒绝）+ API 11 例（写入、清空回轮播、未声明键被丢、五类非法载荷 400、非法更新不落库、列表与详情返回归一化结果）；
- 前端：栅格几何 9 例单测（重叠判定 / 夹取 / 忽略自身 / 空位扫描 / 指针→格换算 / 归一化）；
- E2E（双浏览器）：API 建素材（数据集 → 看板 1 卡 → 大屏）→ 设计器加时钟/文本/仪表盘三类窗格 → 拖动改位次 → 保存并读接口校验落库 → 投屏断言画布渲染（含卡片标题）且无轮播控件；同批回归数据分析主链路（轮播 + 远程控制）确认回退链未破。

## 边界

- 不做自由拖拽像素级定位（栅格吸附）、不做窗格重叠/层级、不做缩放旋转与动画；
- 组件只做三类（文本 / 时钟 / 仪表盘）；图片、视频、地图、自定义 HTML 等按需再扩（扩类型需同时改服务端白名单与前端 `PANE_DEFAULTS`）；
- 批次二（报表设计器：数据集列 → 表格/图表组件 + 模板）另行立项，本 ADR 不覆盖。
