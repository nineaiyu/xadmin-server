# ADR-102：媒体可见性契约（模型图片站内公开，不做记录级数据权限）

- 状态：**已接受**
- 日期：2026-11-03
- 关联：[ADR-100](ADR-100-review-retained-decisions.md)（保留项处置口径同型）、
  `packages/xadmin-common/common/utils/media.py`（模块契约段）、
  [docs/ops/storage.md §5.1](../ops/storage.md)（媒体访问契约）

## 一、背景

总审查后端项指出：`/media/` 原图与按 pk 解析的缩略图（`get_media_path`）对全部
登录用户可见、**不按记录级数据权限过滤**——任何登录用户持有路径即可读模型图片
字段的产物。该项需要产品确认语义（公开 = 文档显式化；非公开 = 按数据权限收敛），
本 ADR 按产品决策登记。

## 二、决策：维持「站内公开」语义，作为显式契约收口

| # | 决策点 | 结论 |
|---|--------|------|
| 1 | 原图与缩略图的权限归属 | **对全部已登录用户可见**：登录鉴权 + `safe_join` 路径收敛 + 内部派生目录 404 + 敏感命名空间签名 URL 是外层防线；不做记录级数据权限过滤 |
| 2 | 为什么缩略图不单独叠加数据权限 | 原图路径本不受记录权限管辖——单独收紧缩略图是**无实效的伪防护**（知晓原图路径即可绕过）；且会破坏跨部门头像渲染（聊天室 / 通讯录 / 审计的列表头像靠 `ProcessedImageField` 直出） |
| 3 | 什么情况下需要做 | 产品语义要求「模型图片按记录权限收敛」时：切换位已就绪（2026-11-04）——`MEDIA_MODEL_IMAGE_VISIBILITY=restricted`（默认 `public` 保持本 ADR 契约零变化），原图直出与缩略图两条路径一并按记录数据权限收敛（无行/不可见一律 404）；切换即接受跨部门头像渲染与「先传后存」表单预览的行为变化 |
| 4 | 敏感图片的正确归宿 | **禁用 `ProcessedImageField`**：应存 `UploadFile` 体系（短时效签名 URL + 归属校验 + 受鉴权 download / preview 端点的数据权限与访问审计）。当前全仓该字段仅承载头像类站内公开资产（URL 含 uuid5 随机段、不可枚举） |

## 三、触发条件（命中后重评本 ADR）

- 产品引入「模型图片需要按记录/部门隔离」的业务语义（如内部相册、水印样张）；
- `ProcessedImageField` 出现非头像类消费点（新模型挂载该字段且承载非公开资产）；
- 出现「缩略图越权读」的实际投诉或安全事件（区别于契约内行为）。

## 四、后果

- 契约落地为代码注释（`media.py` 模块 docstring）+ 运维文档
  （`docs/ops/storage.md` §5.1 媒体访问契约），「公开」不再被误读为疏漏；
- 外层防线（鉴权 / 签名 URL / 敏感命名空间）既有守护测试维持全绿；
- 触发条件命中时按「先修订本 ADR、再独立立项」处理，不在普通业务改动中顺手改
  （与 ADR-100 保留项同口径）。
