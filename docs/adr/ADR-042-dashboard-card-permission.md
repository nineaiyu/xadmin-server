# ADR-042：仪表盘卡片级权限（一期：授权面与读取过滤；二期：字段权限叠加与前端授权 UI）

| 项目 | 内容 |
|------|------|
| 状态 | 一期已交付 2026-09-15；二期（字段权限叠加 + 前端授权 UI + 越权矩阵补强）已交付 2026-09-16 |
| 日期 | 2026-09-15（一期）/ 2026-09-16（二期） |
| 关系 | 扩展 [ADR-020](ADR-020-dataset-dashboard-phase1.md)（数据集/仪表盘一期：卡片级权限与字段权限叠加原为「不做」边界）；候选池「仪表盘卡片级权限与字段权限叠加」销项（一二期全部） |

## 背景

仪表盘一期明确「卡片级权限（跟随数据集权限）」不做——卡片对仪表盘可见者全量展示。
候选池登记「卡片按浏览者细粒度授权；与数据集列白名单联动评审」。

## 决策（一期）

1. **授权面内嵌**：`Dashboard.layout[].allowed_roles`（角色 code 列表，空 = 全员可见），
   随 layout JSON 内嵌，**不建子表**（卡片本身即 layout 内元素，无独立生命周期）。
   - 写入校验：必须为字符串列表，且每个 code 必须存在于 `UserRole.code`（未知 code 拒绝）。
2. **读取过滤**：`DashboardSerializer.to_representation` 调 `utils/dataset.filter_layout_for_user` ——
   - 超管**全量**（与数据权限旁路口径一致）；
   - 非超管按浏览者**在用角色**命中过滤（无命中角色 → 该卡片不可见，fail-closed）；
   - 匿名/未认证 → 空布局（兜底；路由层已做认证）。
3. **只收敛不提权**：卡片过滤只**减少**可见卡片，不改变数据集执行与行级数据权限口径
   （执行仍走 `get_filter_queryset`，fail-closed 不变）。

## 二期（2026-09-16 交付）

1. **字段权限叠加**（挂点 `system/utils/dataset.py` 输出侧）：
   - `viewer_visible_fields(bound_model, user)`：浏览者对绑定模型的字段白名单
     （跨菜单并集；角色解析与 `get_user_field_queryset` 同口径 = 直挂角色 + 部门挂角色，均须启用）；
   - **执行**（`execute_dataset`）：输出列 = 数据集 `columns ∩ 白名单`；交集为空 →
     空结果（`columns/rows/total` 全空，不泄露行数）；
   - **聚合**（`aggregate_dataset`）：`group_by` / `value_field` 不在白名单 →
     `ValidationError`（fail-closed，业务码 1001）——聚合结果会以数值形态泄露
     隐藏列（如薪酬求和），不能按列裁剪只能拒绝；
   - **口径边界（有意与既有字段权限语义不同）**：超管全量；浏览者角色**无任何**
     该模型字段权限配置 → 不裁剪（全量）。既有序列化器字段裁剪是「无白名单=全裁」的
     fail-closed（白名单制），但那是菜单绑定语义；数据集执行无菜单上下文，
     若同样全裁，所有未配置字段权限的普通用户的仪表盘都会被裁空。
     字段权限在此是**显式授权即收敛**：配置了才裁，不配置不裁。
2. **前端授权 UI**：卡片设置弹窗新增「可见角色」多选（`CardForm.vue`），
   选项 = 角色列表（`roleApi.list`，无 `list:SystemRole` 权限时静默降级为空选项，
   已保存的授权值不受影响）；值 = 角色 code，与 `layout[].allowed_roles` 同口径；
   `DashboardCard` 类型补 `allowed_roles?: string[]`。
3. **越权矩阵补强**（集成测试）：跨角色浏览（API 级，同一仪表盘两角色各见其卡片）/
   空角色用户只见无限制卡片 / 超管旁路（API 级 detail 全量）/
   卡片级可见但行级数据权限无授权 → 执行空结果（三层叠加兜底）。

## 测试

`tests/integration/system/test_dashboard_card_permission.py`（18 例）：
一期——无授权卡片全员可见 / 角色不命中全过滤（fail-closed）/ 命中可见 / 超管全量 /
API 拒绝未知角色 code 且接受已知 code；
二期——执行列裁剪（含行键裁剪）/ 无字段配置全量 / 超管全量 / 交集为空返回空结果 /
停用角色白名单失效 / 聚合隐藏分组与取值字段拒绝 / 聚合可见字段放行 /
跨角色浏览（API）/ 空角色 / 超管旁路（API）/ 卡片可见 × 行级 fail-closed 叠加。
E2E：dashboard 主链路覆盖「可见角色」选择与回显。
