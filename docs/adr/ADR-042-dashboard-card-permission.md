| 项目 | 内容 |
|------|------|
| 状态 | 一期已交付 2026-09-15；字段权限叠加与前端授权 UI 待续（见 §待续） |
| 日期 | 2026-09-15 |
| 关系 | 扩展 [ADR-020](ADR-020-dataset-dashboard-phase1.md)（数据集/仪表盘一期：卡片级权限与字段权限叠加原为「不做」边界）；候选池「仪表盘卡片级权限与字段权限叠加」销项（一期） |

## 背景

仪表盘一期明确「卡片级权限（跟随数据集权限）」不做——卡片对仪表盘可见者全量展示。
候选池登记「卡片按浏览者细粒度授权；与数据集列白名单联动评审」。

## 决策（一期）

1. **授权面内嵌**：`Dashboard.layout[].allowed_roles`（角色 code 列表，空 = 全员可见），
   随 layout JSON 内嵌，**不建子表**（卡片本身即 layout 内元素，无独立生命周期）。
   - 写入校验：必须为字符串列表，且每个 code 必须存在于 `UserRole.code`（未知 code 拒绝）。
2. **读取过滤**：`DashboardSerializer.to_representation` 调 `utils/dataset.filter_layout_for_user` ——
   - 超管**全量**（与数据权限旁路口径一致）；
   - 非超管按浏览者**在用角色**命中过滤（无命中角色 → 该卡片不可见，fail-closed）；
   - 匿名/未认证 → 空布局（兜底；路由层已做认证）。
3. **只收敛不提权**：卡片过滤只**减少**可见卡片，不改变数据集执行与行级数据权限口径
   （执行仍走 `get_filter_queryset`，fail-closed 不变）。

## 待续（二期）

- **字段权限叠加**：执行/聚合结果列与浏览者字段白名单求交集，挂点在
  `utils/dataset.py` 的输出侧（`execute_dataset` / `aggregate_dataset` 返回前）；
  口径 = 数据集 `columns ∩ 浏览者可见模型字段`，超管全量、无字段配置 = 全量（与既有字段权限语义一致）；
- **前端**：卡片设置弹窗「可见角色」多选与回显（layout 读写已就绪）；
- **越权矩阵补强**：跨角色浏览 / 超管旁路 / 空角色 / 卡片级与行级叠加场景。

## 测试

`tests/integration/system/test_dashboard_card_permission.py`：
无授权卡片全员可见 / 角色不命中全过滤（fail-closed）/ 命中可见 / 超管全量 /
API 拒绝未知角色 code 且接受已知 code。
