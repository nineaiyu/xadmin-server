# ADR-090：大屏画布进阶四项（富文本扩展 / 旋转 OBB 几何 / 视频与 iframe 窗格 / 模板治理与跨设备剪贴板）

- 日期：2026-10-11
- 状态：**已交付**（2026-10-12：四批全部交付，落地记录见文末）
- 背景：

[ADR-089](ADR-089-screen-canvas-boundary-followups.md) 把边界条目登记为触发制后，产品一次性确认了
其中四项「成本高 / 涉及外部依赖」的范围（本 ADR 固化其口径）：

1. **富文本扩展**：要链接、列表、图片、表格，并且要有工具条；
2. **旋转后的几何**：要**任意角度**下框选 / 吸附 / 对齐按**视觉盒**（不只是 90° 倍数）；
3. **窗格类型**：加**视频**（mp4 / 直链）与**自定义 HTML**（只允许 http(s) iframe 地址）；
4. **模板治理 + 跨设备能力**：模板**目录分组**、**版本历史与回滚**、**跨设备剪贴板**（服务端存储）。

既定约束（前四期不变）：服务端是唯一写权威（白名单 + 校验）；zoom / 表达类字段不污染几何数据；
两套画布（栅格 / 自由）共用一份类型字段口径；`ReResize` 保持通用；行数与 hook 门禁必须过。

## 决策

### D1 富文本扩展（标记子集 → 迷你 Markdown + 选区工具条）

- 标记集**扩展为**：行内 `**粗**` / `*斜*` / `__下划线__` / `~~删除线~~` / `[c=#rrggbb]彩字[/c]`（一期已有）
  **加** 链接 `[文本](http(s)://…)` 与裸 URL 自动识别、图片 `![alt](http(s)://…)`、
  无序列表（`- ` 开头连续行）、有序列表（`1. ` 开头连续行）、表格（`| a | b |` + `|---|---|` 分隔行的 GFM 风格块）；
- **渲染口径不变**：先 `escapeHtml` 全文转义，再套自建标记 → 白名单 HTML（绝不吃外部 HTML）。
  链接强制 `target="_blank" rel="noopener noreferrer"`；图片与链接地址**只收 http(s)**；
  表格单元格内只允许行内标记（不允许嵌套表格 / 列表，避免解析歧义）；
- **工具条形态（口径说明）**：属性面板的文本编辑区升级为「**选区包裹按钮 + 实时预览**」——
  工具条按钮（粗 / 斜 / 下划线 / 删除线 / 颜色 / 链接 / 图片 / 无序列表 / 有序列表 / 表格）
  作用于 textarea 的当前选区插入标记，右侧实时渲染预览；
  **不做** `contenteditable` 真富文本编辑器：粘贴清洗、输入法、撤销栈、选区模型与安全面全量翻新，
  收益与风险不匹配（登记为触发制：出现「必须像 Word 一样所见即所得」的明确诉求时再评）；
- 窗格仍以**纯文本标记**落库（`text_format = rich`），投屏与设计器共用同一渲染函数。

### D2 旋转 OBB 几何（视觉盒参与框选 / 对齐 / 吸附）

- **几何口径（唯一真相）**：
  - 框选命中：选择框（轴对齐）与窗格**旋转矩形**做**相交判定**（SAT，凸多边形标准算法）；
  - 对齐 / 吸附 / 分布 / 组拖动夹取：一律用旋转矩形的**外接轴对齐包围盒（AABB）**参与计算；
  - 回写时**只改未旋转的 x / y / w / h**：先按 AABB 求出目标位置，再换算回未旋转盒
    （`x = aabbTarget - (aabb.x - box.x)`），保证「视觉边缘对齐」且数据语义不变；
- `rotate = 0` 时全部退化为现有轴对齐算法（**逐像素一致**，旧 E2E 期望不漂移）；
- 旋转是视觉的：吸附参考线、组包围盒、框选矩形仍绘制在画布坐标系中，不随窗格旋转；
- 备选（拒绝）：把旋转烘焙进坐标数据 / 引入完整仿射变换层——前者污染数据，后者与「不旋转也能用」
  的既有几何在坐标语义上并存，会出现两套真相。

### D3 视频与自定义 HTML 窗格

- 新增两类窗格（服务端 `SCREEN_PANE_TYPES` 与前端 `PANE_DEFAULTS` 同步）：
  - `video`：`url`（http(s) 的 mp4 / webm 直链）、`poster`（封面，可选）、`fit`（`cover|contain`）、
    `muted`（缺省 true）、`loop`（缺省 true）、`autoplay`（缺省 true）；投屏与预览按「静音自动播放 +
    循环」渲染，编辑态显示封面 / 占位与 URL 校验提示；
  - `html`：`url`（**只允许 http(s) iframe 地址**）、`sandbox`（缺省收紧：
    `allow-scripts allow-same-origin` 之外一律不给）——**不接受原样 HTML**（XSS 面为零）；
- 校验：两类窗格都走「URL 合法性 + 类型白名单」的服务端校验（与图片窗格同一套 URL 口径）；
- 备选（拒绝）：HLS / RTSP 直播（需额外依赖与转码链路）、`srcdoc` 原样 HTML（安全面）、
  地图窗格（供应商未定，维持触发制）。

### D4 模板治理与跨设备剪贴板

- **目录分组**：`ScreenTemplate` 增 `group`（CharField，空 = 未分组）；前端模板菜单按组展示，
  另存 / 重命名时可指定分组；
- **版本历史与回滚**：新增 `ScreenTemplateVersion`（模板外键 + `free_layout` 快照 + 名称 + 版本号），
  保存模板内容时**自动记一版**，保留最近 N 版（N = 10，超出裁剪最旧）；提供「版本列表」与
  **回滚**（回滚本身也记一版，可再回滚回来）；
- **跨设备剪贴板**：新增按用户**单槽**模型 `ScreenClipboard`（creator 唯一约束 + 载荷），
  端点 `screen-clipboard/mine`（GET / PUT / DELETE）；前端复制时**双写**（本地 + 服务端，
  服务端失败只警告不阻断），粘贴默认用本地（快），菜单额外提供「从云端粘贴」；
  权限点与团队模板同款（list / create / partialUpdate / destroy 视端点而定，落种子）；
- 备选（拒绝）：审核流（属组织流程，非产品必需）、跨租户共享（工作区红线）。

## 兼容性与回退

- 富文本标记是**向后兼容的超集**：既有 5 种行内标记行为不变，纯文本窗格（`plain`）完全不受影响；
- 旋转 OBB 只改「几何入口」的判定函数，`rotate = 0` 走原路径（单测钉住逐值一致）；
- 两类新窗格是新增类型，旧载荷不受影响；不支持的旧客户端读新类型窗格会忽略（服务端仍保留数据）；
- 模板分组 / 版本 / 剪贴板都是新增字段与端点，隐藏入口即可回退。

## 落地记录（分批回填）

### 第一批：D1 富文本扩展 + 工具条（2026-10-11 交付）

- **渲染层**：`utils/richText.ts` 改为「块级 + 行内」两段流水线——块级按行扫描
  （表格：`| … |` + `| --- |` 分隔行 > 列表：`- ` / `1. ` 连续行 > 段落，段落内保留 `<br>`），
  行内新增链接 `[文本](http(s)://…)`、裸 URL 自动成链、图片 `![alt](http(s)://…)`，
  既有 5 种行内标记行为不变；输出面新增 `<a> / <img> / <ul> / <ol> / <li> / <table> / <th> / <td>`；
- **安全口径**：仍是「先转义、再套标记」；链接强制 `target="_blank" rel="noopener noreferrer"`，
  链接与图片地址只收 http(s)（`javascript:` / `data:` 一律按普通文本保留）；
  **行内渲染函数刻意不导出**——它要求入参已转义，对外暴露等于开一个「绕过转义拼 HTML」的口子
  （单测里一度直接喂未转义文本，属性里的引号当场逃逸，故收紧导出面）；
- **工具条**：新增 `RichTextEditor.vue`（选区包裹按钮 + 实时预览 + 提示），属性面板在
  `rich` 格式下切换为该编辑器（`plain` 仍是朴素 textarea，老用例零影响）；
  编辑器改用**原生 textarea**——挂在 `el-input` 组件上的 `ref` 拿不到 `selectionStart/End`，
  `slice(undefined)` 会退化成「整串复制」（真实踩坑，单测已钉住）；
- **样式**：新增共享 partial `src/style/screen-richtext.scss`（`@use` 进 `ScreenPane` 的 scoped 样式），
  预览区复用同一套标签样式；
- **测试**：`richText.spec.ts` 重写（13 例：行内 / 块级 / 表格 / 列表 / 非法颜色 / 注入面 /
  未转义文本），新增 `richTextEditor.spec.ts`（5 例：选区包裹 / 占位 / 表格骨架 / 列表前缀 / 预览同源），
  E2E 增「工具条插表格 + 无序列表 → 预览即时可见 → 投屏态窗格同源渲染」；
- **踩坑（YAML）**：多行引号标量（`key: "a"` 换行再 `"b"`）不是合法 YAML，会以
  「All mapping items must start at the same column」在**单测收集阶段**炸掉引用该语言包的用例——

### 踩坑与口径（三、四批）

- **旋转窗格的缩放手势不做吸附**（ADR-090 D2 明说的取舍）：视觉盒尺寸是 w/h 与角度 θ 的耦合函数
  （`span = |w·cosθ| + |h·sinθ|`），逐像素反解在 `cosθ → 0` 时发散；「要么精确、要么不吸附」比
  近似吸附更可预测，而缩放微调不是旋转窗格的高频动作；
- **视觉盒只平移、不改尺寸**：对齐 / 分布 / 组夹取都在视觉 AABB 上算目标，再把位移原样施加到
  未旋转的 x / y——这样旋转永远不会污染坐标数据（rotate = 0 时逐值等于历史行为）；
- 服务端常量被视图模块 import 后**无法用 settings 覆盖**：版本保留数改成运行期读
  `getattr(settings, ...)`（测试里才能把上限调到 3 验证裁剪）；
- 剪贴板「upsert」放在 `create` 里（本人已有槽位则就地更新）：前端不必区分首次 / 再次复制，
  也就不会出现「两条槽位」的脏状态；模型补 `ordering` 以免分页告警。
