# ADR-092：站点级外观配置全局生效与面板条件项补强

- 日期：2026-10-13
- 状态：**已交付**（后端分流与读取权威、前端只读态、种子补齐、单测与 E2E 同批落地）

- 背景：项目配置面板（lay-setting，`configure` 命名空间 92 键）此前**所有键统一写个人配置**
  （`UserPersonalConfig`），读取按「个人行覆盖 + 回落系统值」。由此产生三类「配置不生效」：

1. **站点级字段被个人化**：站点标题 / Logo 品牌位 / 登录页布局改完只有当前账号可见 ——
   登录页（匿名读取系统配置）与其他账号恒为旧值。用户视角就是「改了不生效」。
2. **种子缺键导致无法保存**：`loadjson/systemconfig.json` 的 `WEB_SITE_CONFIG` 缺 `Title`
   键，而写入侧只遍历「既有键」防未知配置入库 —— 「站点标题」的改动被静默丢弃。
3. **条件性偏好无提示**：混合宽度（仅双列布局生效）/ 半暗顶栏（仅浅色外观生效）在不适用的
   形态下仍可编辑，改了看不到效果；页宽区块在 ≤1280 视口整块不渲染，已设「定宽」的用户
   无法改回。

## 决策

### D1 站点级外观键写入系统配置（全局生效）

站点级键集合（9 键，后端硬编码白名单）：

| 键 | 语义 |
|---|---|
| `Title` | 站点标题（品牌区 / 浏览器标签页 / 登录页） |
| `ShowLogo` / `LogoSource` / `LogoSourceDark` / `LogoShowText` / `LogoFit` / `LogoMode` / `FullLogoHeight` | Logo 品牌位 |
| `AuthPageLayout` | 登录页布局（登录前渲染，天然全局） |

- **读取**：`GET /api/system/configs/WEB_SITE_CONFIG` 以系统配置为权威 —— 个人行里的历史值
  （这些键曾是个人偏好）不覆盖，个人行缺席时补齐，保证前端拿到完整站点级字段；
- **写入**：`PATCH` 按站点级 / 个人级分流。站点级键**不沉淀个人行**（历史值随下一次保存自愈
  移除）；系统行按「当前系统值 + 本次更新」合并写回，缓存随写失效（全员即时生效）；
- **权限**：站点级键**实际变化**才要求超管。以下形态不判越权、不误拒普通账号的日常保存：
  提交值与系统值相同（前端整包提交的当前值）、空值（服务端未下发的回落态）、系统行缺该键；
- **缺键自愈**：超管对系统行缺失的站点级键（如历史种子缺 `Title`）的改动可写入补齐；种子已补
  `Title`，新库开箱即有；
- **前端**：非超管在面板中对站点级字段只读（控件 disabled + 「仅管理员可修改」提示），
  避免「改完只对自己生效」的误解。

### D2 其余键保持个人偏好语义

主题 / 布局 / 页签 / 快捷键等仍写个人配置（个人行覆盖 + 回落系统值）；时区（`Timezone`）也
维持个人级 —— 个人时区偏好是合理需求，不做站点化。

### D3 面板条件项补强

- `sidebarMixedWidth`：非双列布局（`!isMixLayout`）禁用，与 `sidebarExtraCollapse` 同口径；
- `semiDarkHeader`：暗色外观（`isDark`）禁用，与 `semiDarkSidebar` 同口径；
- 页宽区块：`stretch` 为定宽（number）时，小视口仍渲染该区块 —— 保证无法改回的形态不存在。

## 边界与登记

- `load_init_json` 重灌会整行覆盖系统配置（含站点级键，既有 loaddata 行为）：重灌种子的窗口
  需注意管理员自定义的站点级取值会被种子值覆盖；
- 前端 `getSiteConfig` 仍是启动时单次拉取：多标签页 / 多设备之间不实时同步（既有口径）；
- 面板条件项以「禁用 + tip」表达生效条件，不改变各偏好本身的实现。

## 验证

- 后端：`tests/integration/test_configs_api.py::TestSiteWideAppearance` 7 例（超管写系统行、
  非超管越权拒绝、整包未变更放行、历史个人值读取忽略、缺键自愈与不误拒）；
- 前端：`e2e/site-wide-config.e2e.ts` 双浏览器 —— 管理员改动后**匿名会话读取即为新值**（全局
  生效硬证据）+ 非管理员站点级字段只读；`layout-preferences.e2e.ts` 修正半暗侧栏断言（选中
  激活项属设计口径，普通项才是断言对象）；
- 门禁：pytest 全量、ruff/行数、前端 typecheck/vitest/eslint/prettier。
