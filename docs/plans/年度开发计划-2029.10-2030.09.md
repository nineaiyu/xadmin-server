## 一、年度定位

前三年完成「功能补课（第一年）→ 平台化深化（第二年）→ 成熟期治理（第三年）」。本年度起进入**稳定运营年**：

- 主基调：**依赖窗口收口 + 按需演进 + 运营常态化**——不设功能军备目标；
- 一切新增以「真实触发」为前提（部署诉求 / 依赖发布 / 演练与审计发现），未触发即维持；
- 资源优先保障运营节奏（演练 / 审计 / 依赖窗口）与文档纪律。

## 六、验证方式（门禁矩阵）

| 层级 | 每窗口出口门禁 |
|------|---------------|
| 后端 | `ruff check/format` + `pytest -n auto` 全量 + 覆盖率 ≥78% + 新增守护测试 |
| 前端 | typecheck + typecheck:strict（全仓）+ eslint + prettier + stylelint + vitest + check:contract + check:bundle-size |
| E2E | 新功能主链路双浏览器 + `test:e2e:fresh`（改后端必跑）+ 视觉回归（基线入库后常态比对） |
| 数据/部署 | 新权限点重灌幂等；迁移全新库重建；升级路径按 `7_upgrade.sh` 预检/回滚口径 |
| 性能/稳定 | k6 场景集基线对比；SLO 看板数据核对（校准后） |
| 治理 | 新功能 100% 带测试；先 ADR 后动手；候选池先对账再排期 |

## 附录 A：明确不做（红线延续）
