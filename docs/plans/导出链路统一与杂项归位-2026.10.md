## 一、Phase D · 三套导出链路统一为 task 域导出服务（commit db314ae5）

统一前：①视图动作链（`packages/xadmin-common/common/core/modelset/import_export/export_actions.py`，同步
`export_data` + 异步 `export_async` 提交）；②任务重放链（`task/services/_export.py`
重建请求重放视图落产物）；③定时报表链（`dataset/report_render.py` + `dataset/analysis_tasks.py`，
自带 `EXPORT_MIME` 与内联产物落库）。

统一后（`task/services/_export.py` 为唯一出口，视图层与任务层各留薄适配）：

| 收口点 | 迁移内容 |
|---|---|
| MIME 单源 | `EXPORT_MIME_TYPES` 全站唯一定义 + `mime_type_for(fmt)`；`dataset/report_render.EXPORT_MIME` 删除，邮件附件与产物 `mime_type` 一律取自注册表 |
| 产物落库 | 新增 `persist_export_artifact(record, filename, content, user)`：UploadFile(is_tmp=True) 落盘 + 挂下载中心记录；异步导出链与报表链共用，记录行落库字段时序仍归各编排方 |
| 进度协议 | 两链均走 `task.utils.task_progress.update_progress`（既有），报表侧里程碑（20/80）移入 try 块 |
| 取消协议 | 报表执行链接入与异步导出同源的 `TaskCancelled → REVOKED` 收敛（原先落 FAILURE 且 re-raise 触发 task_failure 告警——用户取消不是故障）；`mark_execution_revoked` 同步执行历史行 |
| 记账补齐 | 报表执行链在 EAGER/apply 环境补建同 pk `TaskExecution`（与导出/导入链同口径，生产 apply_async 路径仍由 after_task_publish 记账，get_or_create 幂等） |
| 渲染器 | 各链保留自身渲染器（视图重放链 = DRF renderer；报表链 = dataset 工作簿渲染器，多 sheet/聚合形态不适用行写协议），由统一服务负责渲染后的产物/进度/取消/终态 |

新增守护测试：`tests/integration/dataset/test_report_execution.py`（成功路径产物落库/邮件投递 +
取消路径 REVOKED 收敛）。

## 二、Phase E · 归位杂项

### T04-16 · metrics 同名不同域改名（commit 08a931d6）

`system/utils/platform/metrics.py` → `monitor_metrics.py`（与同目录 monitor_events /
monitor_history / monitor_export 家族命名对齐），消除与 `packages/xadmin-common/common/metrics.py`（Prometheus）
的同名异义。消费方经 `import ... as metrics` 别名保持调用面不变；Prometheus 侧不动。

### T04-14 · 顶层 `utils/` 更名 `ops/`（commit 0b1983a4）

该目录实为运维 shell 脚本 + 监控栈资产 + 初始化脚本，与各业务 app 的 utils 子包同名异义：

- `git mv utils ops`；`tests/unit/utils` → `tests/unit/ops`；
- 路径引用同步：compose 挂载/健康检查/entrypoint（容器内路径同步改 `ops/`）、`xadmin.sh`、
  CI workflow、`.gitignore`、`ruff.toml`、`pyproject.toml` 覆盖率清单、docs 运维手册、守护测试；
- 门禁同口径：`check_cross_app_imports` 的 SCAN_DIRS（utils→ops）、`check_doc_paths` 顶层
  前缀、`check_file_length` 目录清单；
- 顺手修正 `scripts/e2e_seed_scenes.py` 注册的演示周期任务名：Phase C 迁位后
  `system.utils.task.ctasks.auto_clean_tmp_file` 已不存在，改指 `system.tasks.auto_clean_tmp_file_job`；
- **部署提示**：镜像为整体 COPY，需重建镜像后健康检查 / 备份入口才指向新路径；
  `xadmin-installer` 仓自身的 `utils/base-images.yml` 不在本仓更名范围。

### T04-15 · seed_demo 移出生产 app（commit 7f615d17）

- 新增 `demo_seed` app（无模型 / 迁移 / 菜单），承载 11 个 `seed_demo_*` 命令
  （自 system 8 个 + approval 3 个迁出；`approval/management/` 目录随之移除），命令名与行为零变化；
- **条件注册**（`server/settings/apps.py`）：`XADMIN_APPS` 含 demo 或 DEBUG/DEBUG_DEV 时装配；
  生产裁剪（非 DEBUG 且未启用 demo）不注册，`manage.py --help` 不再暴露演示数据入口；
- 配套守卫：`system.tasks.demo_account_selfheal_job` 增加 `demo_seed` 未注册短路（生产残留演示
  账号场景跳过自愈）；`ops/init_data.py --with-demo` 同口径显式报错；
- 门禁 ALLOWLIST 与守护测试迁位（`tests/unit/demo_seed/`；`test_command_help` 的 LOCAL_APPS
  纳入 demo_seed）。
