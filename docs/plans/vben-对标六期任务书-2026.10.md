### 3.1 🔶 V6-1 · Tailwind `@theme` 半径/间距/字号/阴影/动效映射补全（维度 4）

**现状**：`src/style/tailwind.css` 的 `@theme inline` 只桥接了 `--color-*`（语义色 + 色阶）与
`--default-transition-*`；`primitives.scss` 里的 `--radius-*`/`--space-*`/`--font-size-*`/`--shadow-*`/
`--duration-*`/`--ease-*` 只能走 CSS 变量，写不了 `rounded-lg`/`p-4`/`text-base`/`shadow-md`/`duration-300`/`ease-out` 工具类。

**方案**：在 `@theme`（或 `@theme inline`）补齐以下映射，全部指向既有令牌（不新造尺度）：

```css
/* 半径 */   --radius-xs/sm/md/lg/xl/full: var(--radius-*);
/* 间距 */   --spacing: var(--space-1);            /* 保持 4px 基准，Tailwind 默认 0.25rem 亦 4px */
/* 字号 */   --text-2xs/…/2xl: var(--font-size-*);  /* 让 text-sm/base/lg 等对齐令牌而非 Tailwind 默认 */
/* 阴影 */   --shadow-sm/md/lg/float: var(--shadow-*);
/* 动效 */   --ease-standard/…: var(--ease-*); --duration-instant/…: var(--duration-*);
```

- **替代方案对比**：① Tailwind `@theme` 映射（推荐，一处声明、工具类即时可用）；② 全站继续用 CSS 变量
  （保持现状，但工具类与令牌两套尺度长期并存）；③ 改 `html { font-size }` 缩放（否决——tailwind `--spacing`
  由 root font-size 推导，会引发全局间距缩放）。
- **风险**：`--spacing` 映射会影响所有 `p-*`/`m-*`/`gap-*` 工具类；`--text-*` 映射会影响 Tailwind 默认字号。
  必须像素中性——若与 Tailwind 默认尺度有差异，**先核对再映射**，差异处保留默认（不强行对齐导致回归）。
- **验证**：`pnpm test:e2e:visual` 不改基线即绿；`check:font-size-literals` 零命中。

### 3.2 🔶 V6-2 · `--pure-*` 真残留清零（维度 4）

**现状**（代码实测）：真残留 34 处——`ReSegmented/src/index.css` 的 `--pure-segmented-*`（18 处）、

`--pure-theme-*`（语义菜单调色板 = 约 230 处）是**有意保留**，非残留。

**方案**：
- `--pure-segmented-*` → 片段组件内部令牌改用语义槽（`--border`/`--fill`/`--radius-*`/`--space-*`）。
- `--pure-z-index-*` → 迁入语义命名（如 `--z-layout/--z-setting-mask/--z-setting-panel/--z-tippy`），
  并同步 `utils/zIndex.ts`（唯一消费源）。
- `--pure-control-padding-*` → `--space-*` 或组件内部令牌。
- `--pure-theme-*` 段补一行「有意保留（菜单调色板，自 theme.scss 迁入，勿当残留清理）」注释。

- **替代方案对比**：① 全量清零并归入语义槽（推荐，消除历史命名心智负担）；② 维持不动（命名不统一只是
  观感，无功能影响）——但与前几期「历史命名清零」的既有方向相悖；③ 重新设计 z-index 阶梯（超范围，EP 弹层
  从 2000 递增，非本任务书边界，维持现有阶梯）。
- **风险**：z-index 是行为敏感值，改名必须保证**值不变**（只改名不改值）。
- **验证**：相关 E2E（弹层/设置面板/ReSegmented 消费方）回归绿；视觉基线不改即绿。

### 3.5 🔶 V6-5 · 弹层类型化 payload 通道（维度 1，评估项）
