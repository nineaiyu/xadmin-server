## 一、年度定位

第七年度完成清账首轮（五仓库推送执行、regen 门禁修复）与安全演练三连（累计 **12 轮**）。本年度延续
持续运营，三个抓手：**清账闭环**（合 main 后 dispatch 视觉基线/Renovate + CSP 页面层）、
**SLO 校准**（数据成熟即执行）、**演练轮换**（剩余场景池：磁盘压力 / 容器资源限制 / DNS 恢复复演）。

## 六、验证方式（门禁矩阵）

| 层级 | 每窗口出口门禁 |
|------|---------------|
| 后端 | `ruff check/format` + `pytest -n auto` 全量 + 覆盖率 ≥78% + 新增守护测试 |
| 前端 | typecheck + strict + eslint + prettier + stylelint + vitest + check:contract（**含 regen 门禁**）+ check:bundle-size（基线 522 KB） |
| E2E | 新功能主链路双浏览器 + `test:e2e:fresh`（改后端必跑）+ 视觉回归（基线入库后常态） |
| 数据/部署 | 新权限点重灌幂等；迁移全新库重建；升级路径按 installer 预检/回滚口径 |
| 性能/稳定 | k6 场景集基线对比；SLO 看板（校准后按新阈值） |
| 治理 | 新功能 100% 带测试；先 ADR 后动手；候选池先对账再排期 |

## 附录 A：明确不做（红线延续）

- 多租户（[ADR-031](../adr/ADR-031-multi-tenant-evaluation.md) 重开条件未命中）；
- 业务模块军备（商城 / CRM / WMS 等）；
- 重依赖（类 Excel 报表设计器、vxe-table、schema-form 等）；
- 适老主题、全面移动端适配（维持既有结论）。
