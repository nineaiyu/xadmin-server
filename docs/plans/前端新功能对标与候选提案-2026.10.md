## 二、先说结论：基础面与工具链已领先，缺口集中在五个方向

**工具链实测**（`xadmin-client/package.json`）：Vite **8.3.5**（Rolldown 已是默认打包器）、
TypeScript **6.0.3**、Pinia **4**、Vue **3.5.42**、Tailwind **4.3.3**、Element Plus **2.14.5**、
echarts **6.1**——对标三框架主流发行版仍在 Vite 5/6 + UnoCSS/Tailwind v3 组合，本仓工具链
**无追赶项**。

**趋势项覆盖盘点**（「已领先」＝对标对象普遍没有）：

| 趋势项 | 本仓现状（证据） | 判定 |
|--------|------------------|------|
| 元数据驱动 CRUD（低代码核心趋势） | RePlusPage + search-columns/search-fields 协议，75 页中 26 页标准页零手写 | **已领先**（框架级 vs 平台级低代码各有定位，见 §五） |
| 7+ 布局模式 / 命令面板（⌘K + 全局搜索 registry）/ 快捷键体系 | `layoutModes.ts` 7 模式判定函数化；`lay-search/` 命令面板带全局搜索组与历史 | 已覆盖 |
| 暗色 + 设计令牌 + 主题预设 | 三层令牌 + 唯一 EP 出口 + 双字面量门禁（审查 02 卷） | 已领先 |
| AI 助手（问答 / NL 查数 / 受限动作）+ MCP 工具面板 + 聊天室 | `integration/ai/` 控制台三入口 + mcp 子域 + Chat 域 | 已覆盖（纵深见 D-1） |
| 可视化搭建（仪表盘 / 报表 / 大屏双画布设计器 + 模板体系四期迭代） | `analysis/` 三设计器，模板/撤销重做/多选对齐齐备 | 已领先（开源后台模板普遍无设计器） |
| 细粒度权限（数据/字段/应用三级 + 权限点种子化） | menu.json/menumeta.json 种子 + sync 门禁 | 已领先 |
| 模板标配件（水印 / 锁屏 / 全屏 / 多标签拖拽与右键菜单 / Excel 导入导出 / 更新检测 / 图形验证码 / 错误页 403·404·500） | 2026-10-25 源码逐项核实：水印 `utils/watermark.ts` + 后端 `FRONT_END_WEB_WATERMARK_*` 配置；锁屏 `lay-lock/`；标签页 `lay-tag/hooks/`（拖拽 + 刷新/关闭其他/固定/最大化）；导入导出 RePlusPage `ExportData/ImportData`（大数据量异步进下载中心）；更新检测 `utils/autoUpdate.ts`（version-rocket 轮询 version.json）；错误页三页 + `module-disabled` | 已覆盖（Vben / pure-admin / JumpServer 的招牌面本仓已齐；微缺口仅水印模板无 IP 占位符——JumpServer 用于溯源，随既有水印能力顺手补，不立项） |

因此本文件的候选全部是**增量方向**，不含任何「补基础」类立项。

## 五、明确不立项清单（含理由，防反复重提）

| 项 | 理由 |
|----|------|
| 多 UI 适配层（Vben 式 antd/naive/tdesign 多套预置） | 本仓组件栈与 Element Plus 深度耦合（appearance 层、ep-bridge、plus-pro-components 表单协议）；元数据协议已承担「换渲染层」的抽象职责，多 UI 适配是三倍维护成本换可替换性，与「模块可裁剪」的定位冲突 |
| shadcn/headless 组件迁移 | EP 覆盖度与既有 60 组件体系成熟；headless 的收益（自由样式）已被令牌体系+appearance 层覆盖 |
| PWA / 离线填报 | 后台场景离线价值低；表单暂存已有草稿机制；移动端整体维持触发制候选池口径 |
| 微前端（qiankun/wujie/module federation） | 二开扩展点（插件 entry point + 契约注入）已验证；模块裁剪六层拦截覆盖了「隔离与组合」的主要诉求；引入微前端框架会破坏首屏闭包治理与门禁体系 |
| 自研图表库替换 echarts | echarts 6 + useECharts 封装 + 主题联动已闭环，无替换收益 |
