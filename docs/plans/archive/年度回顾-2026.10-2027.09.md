## 二、能力盘点（年度新增）

- **身份与协作**：LDAP/AD 同步（值级加密配置）、三家 IM 扫码登录与通知渠道、SCIM 目录同步、PAT/应用 scope；
- **数据与呈现**：数据集 + 仪表盘 + 大屏（ECharts 复用）、报表轻量版（异步导出 + 定时邮件）；
- **智能化**：AI 助手（RAG 引用出处）+ NL 查数（DSL 白名单 + 数据权限 fail-closed + 灰度）；
- **低代码与开放**：动态表单（设计器 → 填报 → 审批挂接）、代码生成器（Model → 四件套 + 页面 + 菜单种子）、
  出站 Webhook（HMAC + 退避重试 + 审计）、开放平台雏形（client-credentials 应用发卡机）、全局搜索、页面水印。

## 四、遗留与开放项（交接清单）

**贯穿尾巴（部署侧，不占窗口）**：CSP report-only → enforce；AES v1 解密关闭；生产异地副本独立故障域核对；
Q3 Renovate 恢复补跑；SCIM 真实 IdP 联调；季度备份演练/audit 周检按节奏执行。

**已登记边界（ADR 评估出口）**：Postgres 全文检索引擎化（zhparser/pg_trgm）；水印菜单级开关与防篡改；
G11 应用级权限体系、OAuth 授权码、回调事件订阅；动态表单 RePlusPage 动态列协议改造；
JWT 审计 3 项已知边界；首屏 -10% 目标未达成的剩余杠杆（index 应用代码拆分）。

**候选池**：ReIcon 瘦身 ✖ 关闭、RePlusPage 动态列协议改造 ✖ 关闭、二开脚手架不立项（生成器已澄清边界）。

**收尾动作（2026-09-14 回填）**：全量 E2E 已跑通（chromium+webkit 251 passed，含 G11 三个新 spec）；
代码审查全轮整改与年度计划全部改动均已提交，两仓库工作区干净。

## 五、下一年度方向建议（2027.10 – 2028.09）

1. **稳定性与运维收口优先**（半年）：把贯穿尾巴清零（CSP enforce、AES v1 关闭、异地副本核对）、
   备份演练制度化、依赖升级节奏化（Django 5.2 LTS 支持至 2028-04，6.x 因 celery 不升，ADR-004 已记录）；
2. **AI 能力深化**：RAG 向量化升级（当前词频检索）、助手写操作（草稿态 + 审批挂接，复用 412 协议）；
3. **开放平台二期**：应用级权限体系、OAuth 授权码、回调事件订阅（与出站 webhook 合并评估）、
   按应用用量报表；
4. **多租户**：仅当 ADR-031 的重开条件命中时启动，优先「实例编排自动化」而非行级多租户；
5. **体验债**：首屏体积（应用代码拆分）、动态表单列表能力（若出现导入导出诉求再评估）。
