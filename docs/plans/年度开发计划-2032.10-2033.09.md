## 一、年度定位

第六年度完成演练体系化（累计 **9 轮**，连接 / 存储 / 配置三层零缺陷）。本年度延续持续运营：

1. **清账**（T3/T5）——推送到位即执行（清单已就绪）；
2. **SLO 校准**（T6）——数据成熟即执行并回填；
3. **演练轮换**——剩余场景池：**磁盘压力 / 容器资源限制 / DNS 恢复流程复演**；
4. **十年节点全景盘点**（T11，2033-09）——十年文档链 / 能力矩阵 / KPI 纵览。

## 六、验证方式（门禁矩阵）

| 层级 | 每窗口出口门禁 |
|------|---------------|
| 后端 | `ruff check/format` + `pytest -n auto` 全量 + 覆盖率 ≥78% + 新增守护测试 |
| 前端 | typecheck + strict + eslint + prettier + stylelint + vitest + check:contract + check:bundle-size（基线 522 KB） |
| E2E | 新功能主链路双浏览器 + `test:e2e:fresh`（改后端必跑）+ 视觉回归（基线入库后常态） |
| 数据/部署 | 新权限点重灌幂等；迁移全新库重建；升级路径按 installer 预检/回滚口径 |
| 性能/稳定 | k6 场景集基线对比；SLO 看板（校准后按新阈值） |
| 治理 | 新功能 100% 带测试；先 ADR 后动手；候选池先对账再排期 |

## 附录 A：明确不做（红线延续）

- 多租户（[ADR-031](../adr/ADR-031-multi-tenant-evaluation.md) 重开条件未命中）；
