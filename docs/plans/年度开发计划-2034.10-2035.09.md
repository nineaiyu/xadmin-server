## 一、年度定位

第八年度完成演练剩余池 3 轮轮换（累计 **15 轮**）、修复 CI 长期失守（双语断言）并固化复核项。
本年度延续持续运营，四个抓手：

1. **清账闭环**（T3/T5）——合 main 即执行（视觉基线 / Renovate 验收 / CSP 页面层）；
2. **SLO 校准**（T6）——数据成熟即执行并回填；
3. **告警可观测补强**——`container oom` 事件接入（第十五轮登记）+ 剩余告警面盘点；
4. **演练收尾**——真丢包部署级观察（NET_ADMIN 环境）。

| 层级 | 每窗口出口门禁 |

| E2E | 新功能主链路双浏览器 + `test:e2e:fresh`（改后端必跑）+ 视觉回归（基线入库后常态） |

| CI | GitHub Actions（Unit Tests / Lint / E2E / security）全绿 + 无积压失败 |
| 治理 | 新功能 100% 带测试；先 ADR 后动手；候选池先对账再排期 |
