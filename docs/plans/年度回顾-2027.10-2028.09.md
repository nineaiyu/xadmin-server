## 二、能力盘点（年度新增）

- **AI（从问答到执行）**：受限动作注册表（`/do` + 确认卡片 + 权限双门 + 412 复用 + `auth_type=ai` 审计 + 灰度）、
  检索评测集入 CI（36 问 hit@5 97.2%）、知识库管理（双来源文档 / 分块 / 批量启停用）、聊天室二期
  （AI 流式 SSE / 历史清理 / 表情 / 桌面通知）；
- **开放平台（二期全量）**：应用级四级授权（模型 × 动作 × 字段 × 行）、OAuth 授权码 + PKCE、
  用量与配额报表、Webhook 事件契约（`schema_version` + 自动生成文档）；
- **安全（两硬门禁闭环）**：CSP Django 侧切 enforce（合成上报隔离使判据可判）+ 页面侧护栏落配置（report-only）、
  AES v1 解密关闭（顺带修复「开关未转发到 settings」的死开关缺陷）、发布窗口 checklist 制度化；
- **运维（数据安全）**：PITR 启用（WAL 归档 + gzip + 滞后告警）并完成首次时间点回放演练（时间点语义双重验证）、
  异地副本核对（未启用 + 机制就绪登记）；
- **工程（框架与资产）**：全仓 strict 类型债务清零（门禁收敛全仓）、视觉回归门禁接线、首屏拆包
  （wangeditor 懒注册等，闭包 -36.8% → 519.6 KB）、测试日志与生产日志隔离（硬门禁判据来源保护）、
  `common/decorators` 拆包 + 惰性初始化；
- **平台功能余量**：审批流三期（动作 MFA / 委托代理）、LDAP 组角色映射、IM 账号代录、
  报表 cron 表达式、仪表盘卡片级权限（含字段权限叠加）、远程联想（SuggestSelect）。

## 五、第三年度方向（详见年度开发计划）

项目越过「功能补课」（第一年度）与「平台化深化」（第二年度）后进入**平台成熟期**：
