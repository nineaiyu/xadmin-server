# 交互式验证码底图

当前实现不依赖二进制图片资源：`captcha/backends/art.py` 内置 12 组浅色渐变配色，运行时
程序化生成渐变 + 圆形/斜线纹理 + 噪点底图；旋转题额外绘制「天空 / 太阳 / 地平线 / 山」
场景，用自然景物提供明确的正向语义（不叠加箭头等人工标记）；旋转时先生成 sqrt(2) 倍
场景再中心裁切，避免扩边填充露出的黑色三角。

这样做的原因：

1. 离线私有化部署不引入外部素材版权与体积负担；
2. 每次出题都带随机纹理与噪点，避免固定底图被模板匹配；
3. 方案 §6.2 已允许「程序化渐变 + 噪声图兜底」。

如需替换为 CC0 照片包：把 `make_background` / `make_orientation_scene` 改为读取本目录图片
并随机裁剪即可，调用方（slider / rotate / wordclick）无需改动；新增图片必须在本文件登记
来源与许可（仅收 CC0 / 自绘）。
